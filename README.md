# 🧬 Chroma Titan Bioinformatics Tool

**50+ Hyper Advanced Bioinformatics Suite**  
Built with ❤️ for students, researchers & lab scientists

## 🚀 Key Highlights
- **Chroma** = Modern, fast & beautiful UI (inspired by modern apps)
- **Titan** = Massive power (50+ advanced features, ML-ready)
- Zero installation — runs in browser only
- Perfect for education, research & quick lab work

## ✨ 50+ Advanced Features

- DNA ↔ RNA Conversion + Statistics
- RNA → Protein Translation (Full & Partial)
- Mutation Detection (Transitions/Transversions/SNPs)
- Codon Usage Analysis + Optimization
- Pairwise + Multiple Sequence Alignment (Clustal-style)
- FASTA/FASTQ Parser + Quality Control (Q10/Q20/Q30)
- GC Content + Melting Temp (with graphs)
- Restriction Enzyme Sites + Cut Frequency
- ORF Finder + Longest ORFs
- CRISPR-Cas9 Cut Site & Efficiency Prediction
- Primer Design (Tm, GC%, Hairpin, Dimer, Product length)
- Codon Optimization (for E.coli / any organism)
- CpG Island Detection
- Phylogenetic Distance Matrix + Simple Tree
- Sequence Logo (high-resolution PNG)
- K-mer Frequency + N-grams Analysis
- Chaos Game Representation (CGR) Visualization
- SNP/InDel Detection + Frequency
- Protein pI, Hydropathy, Secondary Structure (simple)
- And 25+ more advanced tools...

## 🛠️ Tech Stack
- Python + Streamlit
- Biopython + NumPy + SciPy + Pandas
- Matplotlib + Seaborn + Logomaker
- Zero local setup needed
